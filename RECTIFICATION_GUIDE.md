# Image Rectification Guide

## Overview

The `rectify_images.py` script allows you to rectify (undistort) fisheye camera images using calibration parameters obtained from the calibration process. This guide explains how to use the script and what results to expect.

## What is Image Rectification?

Image rectification is the process of transforming images to:
1. **Remove lens distortion** - Corrects the curved lines caused by fisheye lens distortion
2. **Align stereo pairs** - For stereo cameras, makes corresponding points appear on the same horizontal line
3. **Simplify stereo matching** - Rectified stereo images can be processed more efficiently for depth estimation

## Prerequisites

Before running the rectification script, you need:

1. **Calibration results** - A YAML file generated by `calibrate` or `calibrate_ds`
2. **Python dependencies** - Install with:
   ```bash
   pip3 install opencv-contrib-python pyyaml numpy
   ```
3. **Input images** - The images you want to rectify (can be different from calibration images)

## Usage

### Basic Stereo Rectification

Rectify both left and right camera images:

```bash
python3 rectify_images.py \
  -c output/cam_stereo.yml \
  -i imgs/ \
  -o imgs_rectified/ \
  -l left \
  -r right
```

**Parameters:**
- `-c` / `--calib`: Path to calibration YAML file
- `-i` / `--input`: Directory containing input images
- `-o` / `--output`: Directory to save rectified images
- `-l` / `--left`: Prefix for left camera images (e.g., "left")
- `-r` / `--right`: Prefix for right camera images (e.g., "right")

### Monocular Rectification

Rectify only left camera images:

```bash
python3 rectify_images.py \
  -c output/cam_stereo.yml \
  -i imgs/ \
  -o imgs_rectified/ \
  -l left \
  --mono
```

### Custom Image Extension

If your images use a different extension (e.g., BMP):

```bash
python3 rectify_images.py \
  -c output/cam_stereo.yml \
  -i imgs/ \
  -o imgs_rectified/ \
  -l left \
  -r right \
  -e bmp
```

## Supported Camera Models

The script automatically detects the camera model from the calibration file and applies the appropriate rectification:

### 1. Fisheye Model (Default)

- **Model type**: `fisheye`
- **Use case**: Standard fisheye lenses (FOV up to ~200°)
- **Method**: Uses OpenCV's `cv2.fisheye.initUndistortRectifyMap()`
- **Parameters used**: K1, K2, D1, D2, R1, R2, P1, P2

### 2. Omnidirectional Model

- **Model type**: `omnidir`
- **Use case**: Extreme wide-angle lenses (FOV > 200°)
- **Method**: Uses OpenCV's `cv2.omnidir.initUndistortRectifyMap()`
- **Parameters used**: K1, K2, D1, D2, xi1, xi2, R1, R2, P1, P2

### 3. Double-Sphere Model (Approximation)

- **Model type**: `double_sphere`
- **Use case**: High-precision applications
- **Method**: Uses fisheye approximation (k1-k4 coefficients only)
- **Note**: For best results with double-sphere model, consider using C++ implementation

⚠️ **Note**: The script provides a fisheye approximation for double-sphere models. For the most accurate undistortion with double-sphere calibration, custom C++ implementation would be needed that uses all 6 distortion coefficients and the xi/alpha parameters.

## Output

The script generates rectified images with the following naming convention:
- Original names are preserved with `_rectified` suffix
- Example: `left1.jpg` → `left1_rectified.jpg`, `right15.jpg` → `right15_rectified.jpg`
- Output format matches the input extension (jpg, bmp, png, etc.)

## Example Workflow

Here's a complete workflow from calibration to rectification:

```bash
# 1. Run calibration
./calibrate -w 9 -h 6 -s 0.02423 -d imgs/ -l left -r right -o output/cam_stereo.yml

# 2. Check calibration results
python3 read_calibration_results.py output/cam_stereo.yml

# 3. Rectify images
python3 rectify_images.py -c output/cam_stereo.yml -i imgs/ -o imgs_rectified/ -l left -r right

# 4. Verify rectified images
ls -lh imgs_rectified/
```

## Understanding Rectification Results

### What to Expect

After rectification, you should observe:

1. **Straight lines**: Lines that were curved in the original fisheye image should appear straight
2. **Reduced FOV**: Rectified images typically have a smaller field of view than the original
3. **Black borders**: Some black regions may appear at image edges (this is normal)
4. **Aligned stereo pairs**: For stereo images, corresponding points should be on the same horizontal line

### Quality Indicators

- **Good rectification**: Objects in the scene appear natural, with minimal warping in the center
- **Edge distortion**: Some distortion near edges is acceptable, especially for extreme fisheye lenses
- **Stereo alignment**: In stereo pairs, the same feature should have the same Y-coordinate

## Troubleshooting

### Error: "No images found with prefix"

**Solution**: Check that your image prefix matches the actual filenames:
```bash
ls imgs/left*.jpg  # Verify files exist
```

### Error: "Cannot read calibration file"

**Solution**: Verify the calibration file exists and has correct format:
```bash
ls -la output/cam_stereo.yml
python3 read_calibration_results.py output/cam_stereo.yml
```

### Poor rectification quality

**Possible causes:**
1. **Poor calibration**: Check calibration accuracy metrics
2. **Wrong camera model**: Ensure you're using the right model for your lens
3. **New images very different**: Rectification works best on images similar to calibration images

**Solutions:**
- Re-run calibration with better quality images
- Use `utils/pre_calibration_check.py` to filter calibration images
- Try different camera models (fisheye vs omnidir vs double-sphere)

### Memory issues with large images

**Solution**: Process images in batches or reduce image resolution:
```bash
# Process first 10 images only (modify the script or manually select)
# Or resize images before rectification
```

## Performance Notes

- **Speed**: Typically processes 1-2 images per second on modern hardware
- **Memory**: Requires ~3x the image size in RAM (for map storage)
- **Batch processing**: The script processes images sequentially with progress updates

## Advanced Usage

### Using with Different Image Sets

You can rectify different images than those used for calibration, as long as they're from the same camera setup:

```bash
# Calibrate with imgs/
./calibrate -w 9 -h 6 -s 0.02423 -d imgs/ -l left -r right -o output/cam_stereo.yml

# Rectify different images with the same calibration
python3 rectify_images.py -c output/cam_stereo.yml -i new_imgs/ -o new_imgs_rectified/ -l left -r right
```

### Integration with Other Tools

The rectified images can be used with:
- Stereo matching algorithms (e.g., OpenCV's StereoBM, StereoSGBM)
- Depth estimation tools
- 3D reconstruction pipelines
- Visual SLAM systems
